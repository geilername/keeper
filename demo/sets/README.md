# Burst sets

Each directory here is one burst that `camera-sim` can upload:

```sh
curl -X POST 'http://localhost:<camera-sim port>/shoot?set=beach-dog'        # the burst
curl -X POST 'http://localhost:<camera-sim port>/shoot?set=beach-dog&dup=1'  # + a duplicate at the end
curl http://localhost:<camera-sim port>/sets                                 # what is available
```

camera-sim uploads every `*.jpg` / `*.jpeg` in the directory in **filename
order**, one every `FRAME_INTERVAL` (300 ms). It ignores other files (such as
`expected.json`) and subdirectories. Each file keeps its own name on the FTP
server, so names must be unique across sets: a frame with the same name as an
earlier upload overwrites it in `/spool/incoming` (ingest still tells them
apart by sha256).

## Generated sets (CC0)

`beach-dog`, `road-dog` and `island-dog` are generated by `demo/generate.sh`
from CC0 photos (see `demo/SOURCES.md`). Each has 6 frames 0.3 s apart and an
`expected.json` saying which frames are degraded on purpose (`blur`,
`under`, `over`). None have faces, so the scorer reports `no_face` for them.

## Adding your own shoot (faces, blinks)

Real bursts with people come from the author's own shoot, **with consent from
everyone pictured** (hackathon rule 4). To add one:

1. Create `demo/sets/<name>/`. Use letters, digits, `.`, `_` and `-` only,
   starting with a letter or digit (other names are rejected).
2. Copy the burst's JPEGs in. Camera names like `DSC01234.JPG` sort
   correctly. Prefix them if another set could have the same names.
3. Keep the EXIF: the culler groups bursts by `DateTimeOriginal` plus
   `SubSecTimeOriginal`. Turn on sub-second time stamps if the camera can.
4. Keep each file at or under 2 MB if the set is committed: export at about
   1800 px on the long edge, quality 85–90. Strip GPS before committing
   (for example `exiftool -gps:all= -overwrite_original demo/sets/<name>/*.jpg`).
5. Optional: add `expected.json` with the same shape as the generated sets,
   to note which frames should win.

No restart is needed: camera-sim reads the directory on every request (it is
mounted read-only at `/demo/sets`).
